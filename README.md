# BostaAlbums

BostaAlbums is an iOS application that allows users to view albums and their associated photos. It provides a detailed view of each album, including the ability to search and filter the photos.

## Features
- Displays albums and their photos in a collection view.
- Supports search functionality to filter photos within an album.
- Uses `SDWebImage` to asynchronously load and cache images.
- Displays album details such as album name.
